# SOC runbooks

Runbooks guide authorized responders through triage, containment, evidence preservation, recovery, communication, and closure. Record every action and timestamp in an incident record. Destructive containment, customer notification, credential revocation, or law-enforcement contact follows the assigned incident commander's authority and applicable policy.

| Runbook | Use it for |
| --- | --- |
| [Account takeover](ACCOUNT-TAKEOVER.md) | Suspicious administrator sign-in, MFA removal, stolen credentials |
| [Sign-in abuse](SIGN-IN-ABUSE.md) | Code guessing, email testing, inbox flooding, or failing sign-in email at `id.oxinov.com` |
| [Cross-tenant access](CROSS-TENANT-ACCESS.md) | Data seen or changed across schools or workspaces |
| [Payment webhook abuse](PAYMENT-WEBHOOK-ABUSE.md) | Forged, replayed, or inconsistent payment events |
