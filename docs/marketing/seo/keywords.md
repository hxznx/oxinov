## Rules

- One main keyword per page; never two pages targeting the same one.
- Use the words people search, in plain English; avoid jargon only we use.
- Put the main keyword in the title, the `h1`, the description, and the first paragraph, naturally. No keyword stuffing.
- Review this table monthly against Search Console queries and countries ([measurement.md](measurement.md)).
