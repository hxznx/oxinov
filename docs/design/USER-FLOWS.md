# User flows

1. **Tenant owner:** verify email -> create workspace -> choose template and address -> preview branding -> invite staff -> publish first course.
2. **Learner:** discover tenant course -> enroll or pay -> watch/listen -> chapter practice -> mock exam -> result -> certificate.
3. **Instructor:** create course -> record/upload media -> create questions and assignments -> submit for review -> grade and support learners.
4. **Admin:** approve instructor/content -> manage student and payment issues -> review reports and audit history.
5. **Multi-tenant user:** sign in -> view memberships -> switch workspace -> see only that tenant's data and branding.
6. **AI author:** prompt -> proposal and changed-record preview -> confirm draft -> edit -> submit for normal review.

Detailed expected outcomes are in [acceptance criteria](../planning/ACCEPTANCE-CRITERIA.md).
