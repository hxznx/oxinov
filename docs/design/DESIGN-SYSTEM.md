# Design system

Use shared semantic tokens for background, text, border, focus, success, warning, danger, and brand accent. Tenant themes may change logo, brand colors, typography, and public-page content while semantic contrast and focus visibility remain valid.

Shared components: navigation, tenant switcher, course card, lesson player, exam timer/question, result summary, chat thread, data table, form field, confirmation dialog, and AI change preview. Document states for loading, empty, error, disabled, and success. Web uses accessible shadcn/ui patterns; mobile uses native React Native controls with equivalent behavior.

Final palette, type scale, and spacing tokens await visual design approval. Track them here before implementation.
