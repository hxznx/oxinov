# Deployment architecture

Docker images: frontend, backend, worker, and chat. PostgreSQL runs in Docker on durable encrypted storage with backup and restore procedures; Redis is disposable. TLS ingress routes tenant subdomains and verified custom domains. Private networks protect database, queue, exporter, and application metric endpoints. Object storage and Mux hold files/video.

Compose supports local and initial single-host deployments. The local `monitoring` profile runs Prometheus, Alertmanager, Grafana, and database/cache exporters. For production, select managed or highly available metric storage, durable retention, authenticated Grafana access, encrypted alert receivers, and an owner for each alert before launch. Kubernetes manifests in `k8s/` are templates for a later orchestrated topology and are not production-ready until image registry, ingress, secrets, persistent volumes, monitoring discovery, and provider settings are selected. Terraform and Ansible are similarly unconfigured. See [architecture](../architecture/ARCHITECTURE.md) and [observability](OBSERVABILITY.md).
