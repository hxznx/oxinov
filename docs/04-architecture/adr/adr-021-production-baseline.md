# ADR-021: Production baseline until scale-out (media, cache, secrets, environments, monitoring)

**Date:** 2026-09-26. **Status:** Accepted (records decisions already built under ADR-017 and ADR-018 and the owner's US$50 budget; owner request of 2026-09-26 to align all documents with reality). Supersedes, for the starter phase only, the Mux, Redis/ElastiCache, Secrets Manager, staging, and production Prometheus choices in ADR-004, ADR-009, and the [technology stacks](../../02-products/edu/edu-tech-stack.md). The current picture is kept in [CURRENT-STATE.md](../current-state.md).

1. **Lesson media on private S3, no video platform.** Uploads and playback use short-lived presigned URLs from `lms-api`; files play as uploaded. Mux (or AWS Elemental MediaConvert to HLS with CloudFront signed URLs) arrives when learners on slow connections need adaptive streaming or protected paid video, measured by playback failures and rebuffering (NFR-02).
2. **No Redis until a measured need.** Nothing in production needs a cache, queue, or fanout yet. The first need chooses between SQS (pay per use, fits ADR-019 events) and a Redis-compatible cache; Redis never holds records of truth.
3. **Secrets in SSM Parameter Store SecureStrings,** generated on the server and rendered into an encrypted Kubernetes Secret. Secrets Manager is used only where automatic rotation is required (for example RDS credentials at scale).
4. **No staging environment.** Delivery changes are rehearsed on a throwaway local k3s with the production versions (`rehearse-local.sh`), and every release is health-checked, smoke-tested, and rolled back automatically (NFR-17). Staging and preview environments with automatic promotion arrive in [DevOps roadmap](../../10-devops/devops-roadmap.md) Phase 4, when a second developer joins or the first school pays.
5. **Production monitoring through CloudWatch alarms, Kubernetes health checks, and the release smoke test.** The Prometheus, Alertmanager, and Grafana configuration (ADR-004) stays version-controlled and checked in CI, and runs locally; production metrics and traces arrive through OpenTelemetry (ADR-019 step 5) with a hosted or right-sized backend.
6. **AWS security services by trigger:** a CloudTrail trail with S3 retention and GuardDuty are the first additions (small monthly cost, owner approval); AWS Config, Security Hub, WAF, and a SIEM follow paying customers or regulated data ([security roadmap](../../09-security/security-baseline.md#roadmap)).

Consequences: lower cost and fewer moving parts now; video is not adaptive, and there is no pre-production environment with real data shapes, so releases rely on tests, rehearsal, and automatic rollback; each item has a stated trigger and moves without changing application contracts. Alternatives considered: adopting the full target stack now (several times the budget) and dropping the target designs from the documents (they remain the plan for scale).
