# Measurement

[SEO index](README.md) · Data: [Search Console and Bing](search-console.md)

The website has no analytics or cookies. Search data comes from Search Console and Bing Webmaster Tools, which need nothing on the site.

## Targets by month 6

| Metric | Target | Tool |
| --- | --- | --- |
| Pages indexed | All public pages | Search Console, Bing |
| Clicks from search | 3,000 per month, from 10 or more countries | Search Console |
| Branded position ("Oxinov") | 1 worldwide | Search Console |
| Core Web Vitals | All "good" | Search Console, PageSpeed Insights |
| Rich results | Organization, breadcrumbs, and FAQ valid | Search Console, Rich Results Test |

## Monthly review (about 30 minutes)

1. **Performance:** clicks, impressions, and average position, compared with last month; top 10 queries and top 10 countries.
2. **New opportunities:** queries with many impressions but few clicks → improve that page's title and description; new queries → add to [keywords.md](keywords.md).
3. **Pages:** any public page not indexed → find out why and fix it.
4. **Experience:** Core Web Vitals and HTTPS reports have no issues.
5. **Enhancements:** breadcrumbs and other rich results have no errors.
6. Record the numbers in the log below.
