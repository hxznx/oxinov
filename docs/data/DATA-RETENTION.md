# Data retention and deletion

Retention periods are product/legal decisions by launch region. Define periods for accounts, recordings, chat, exams, payments, audit logs, and backups before launch. Financial records may need longer retention than learner-facing content.

A tenant owner can request export before cancellation. Suspension preserves data; deletion requires identity verification, a documented delay, removal from live stores and caches, and a backup-expiry schedule. Keep a minimal deletion audit record without retaining private content. See [privacy](../security/PRIVACY.md).
