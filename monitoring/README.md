# Monitoring

Prometheus scrape configuration and rules, Alertmanager routing, and Grafana provisioning live here. Use `docker compose --profile monitoring up -d` from the repository root for local monitoring. See `docs/10-devops/observability.md` for metric contracts and production requirements.
