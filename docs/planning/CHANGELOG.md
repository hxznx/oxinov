# Project changelog

- **2026-09-24, v1.13:** Proposed the Oxinov subscription model (ADR-012): one Free, Plus, Pro, Business, and Enterprise ladder across products, the Oxinov One bundle, feature and limit tables per product, marketplace commission and promotion revenue, entitlement-key and usage-limit checks instead of plan names, web and app-store billing channels, and prepaid Nepal billing. Added pricing risks and the roadmap step.
- **2026-09-24, v1.12:** Organized the repository as company → website → platform → products with a documentation map (`docs/README.md`). Added one-account sign-in with Google and email one-time codes, single sign-on across all products, automatic member access, progressive trust levels T0–T4, and just-in-time policy acceptance (ADR-011, `IDENTITY-AND-ACCESS.md`). Added the platform policy framework, the product plane template with a separate frontend, backend, and database per product, and access tables in each product charter. Updated the Phase 2 build command, AGENTS, README, auth and error contracts, threat model, privacy, data retention, risks, tasks, environments, and the validation script.

Added draft product charters under `docs/products/`, assigned their subdomains and release order in the company blueprint, moved duplicated identity, KYC, payments, messaging, and learning capabilities to the platform and OxinovLMS, and added the rights-confirmation and secret-rotation preconditions to the roadmap.
- **2026-09-24, v1.10:** Mapped the ten strategic pillars from the incorporation objectives to public division pages and future application addresses on `oxinov.com`. Added a candidate module backlog for each pillar, with regulated modules flagged, and a suggested evaluation order to the company blueprint. Updated the Phase 1 build command to create one division page per pillar.

Defined Mumbai primary and Hyderabad recovery-copy regions, AWS Organizations accounts, separate environment VPCs and CIDRs, two-AZ subnet tiers, ECS Fargate, ECR, RDS PostgreSQL, ElastiCache, S3, CloudFront/WAF, Route 53, Secrets Manager/KMS, GitHub Actions OIDC, security controls, cost controls, Terraform structure, and the later EKS decision gate. Added the company blueprint, domain strategy, shared-control-plane and product-plane architecture, current stack selection, target repository structure, company roadmap, and milestone-scoped AI build command. Adopted provider-neutral OIDC with Keycloak as the default, replaced the assumption of Stripe availability for the Nepal entity with a payment adapter and Nepal-provider evaluation, and recorded ADR-008.
