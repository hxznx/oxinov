# Oxinov API gateway

Approved boundary for `api.oxinov.com` routing, authentication hand-off, rate limits, and edge
policy. The gateway must not contain platform or product business rules. No runtime is scaffolded
until the gateway milestone has an approved contract and deployment owner.
